Skin Glow Analyzer

Aplikasi berbasis web interaktif untuk mendeteksi 4 tipe karakteristik kulit wajah (`Acne`, `Dry`, `Normal`, `Oily`) menggunakan arsitektur Deep Learning **MobileNetV2** dan diimplementasikan menggunakan framework **Streamlit**.

Fitur Utama
- **Deteksi Citra Digital (AI):** Mengidentifikasi tipe kulit dominan berdasarkan unggahan foto wajah (*bare face*) atau tangkapan kamera secara real-time.
- **Metrik Presisi Probabilitas:** Menampilkan persentase akurasi prediksi komputasi mesin untuk tiap kelas kondisi kulit.
- **Rekomendasi 5-Step Pemakaian:** Memberikan saran kombinasi bahan aktif dan urutan produk perawatan (*skincare routine*) yang sesuai.

Teknologi & Library
- **Bahasa Pemrograman:** Python
- **Framework Web:** Streamlit
- **Deep Learning Framework:** TensorFlow / Keras
- **Image Processing:** Pillow (PIL) & NumPy
